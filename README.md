# receipts

Проект для распознавания товарных позиций на российских кассовых чеках: пользователь загружает фотографию чека, а модель извлекает из неё список купленных товаров и стоимость каждой позиции.

Выполняется в рамках [курса](https://github.com/job-modelware-ru/ml-2026/blob/main/student.md)

## Цель проекта

Реализовать веб-приложение, которое преобразует изображение чека в структурированный результат:

```json
{
  "items": [
    {
      "name": "Молоко Простоквашино",
      "sum": "89.99"
    },
    {
      "name": "Хлеб Бородинский",
      "sum": "64.99"
    }
  ]
}
```

## Dataset

Основной набор данных — [cdek-ocr/receipt-ocr-ru](https://huggingface.co/datasets/cdek-ocr/receipt-ocr-ru).

Это набор российских розничных чеков с изображениями и структурированной OCR-разметкой. Датасет опубликован под лицензией MIT. Полный набор данных не хранится в репозитории.

### Основные поля датасета

| Поле | Тип | Назначение |
|---|---|---|
| `image_id` | `string` | Идентификатор изображения |
| `file_name` | `string` | Имя файла изображения |
| `image` | `image` | Фотография кассового чека |
| `annotation_format` | `string` | Формат аннотации |
| `annotations_raw` | `string` | Исходная структурированная аннотация |
| `seller_text` | `string` | Название продавца |
| `inn_text` | `string` | ИНН продавца |
| `date_text` | `string` | Дата чека |
| `total_text` | `string` | Итоговая сумма чека |
| `item_texts` | `list[string]` | Названия товарных позиций |
| `item_quantities` | `list[string]` | Количество товара |
| `item_prices` | `list[string]` | Цена единицы товара |
| `item_sums` | `list[string]` | Сумма каждой товарной позиции |
| `item_confidences` | `list[float32]` | Confidence scores для товарных позиций |

Для работы будут использоваться прежде всего поля `image`, `item_texts` и `item_sums`

## Модель

Основная модель — [Donut](https://github.com/clovaai/donut), OCR-free Document Understanding Transformer.

В качестве исходной модели для fine-tuning используется [naver-clova-ix/donut-base](https://huggingface.co/naver-clova-ix/donut-base).

Donut принимает изображение документа и генерирует структурированный текстовый результат. В нашем случае целевая последовательность будет описывать список товаров и их стоимость, например:

```text
<receipt><item><name>Молоко Простоквашино</name><sum>89.99</sum></item></receipt>
```

## Definition of Done

В рамках MVP распознаются только:

- название товарной позиции;
- стоимость товарной позиции.

считается выполненным, если:

- [ ] приложение запускается локально по инструкции из README;
- [ ] пользователь может загрузить фотографию кассового чека через web-интерфейс;
- [ ] изображение передаётся в Python inference service;
- [ ] inference service загружает обученный checkpoint Donut;
- [ ] модель возвращает JSON формата `{ "items": [{ "name": "...", "sum": "..." }] }`;
- [ ] в web-интерфейсе отображаются распознанные названия и суммы товаров;
- [ ] пользователь может вручную исправить распознанные значения;

## Что не входит в цели

- распознавание всех реквизитов чека;
- полноценный учёт финансов и история покупок;
- авторизация пользователей;
- база данных товаров;
- мобильное приложение;
- production deployment;
- распределённая или микросервисная архитектура.
