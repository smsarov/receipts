# Локальный клиент

Запустите API по инструкции в [backend/README.md](../backend/README.md), затем в отдельном терминале:

```bash
cd frontend
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://127.0.0.1:5173). Сервер разработки перенаправляет `/api` на `127.0.0.1:8000`. Выберите или перетащите фотографию, нажмите «Распознать чек» и проверьте найденные позиции.

Для проверки сборки: `npm run build`. Эта сборка — только фронтенд; при запуске без Vite нужно настроить проксирование `/api` к бэкенду.
