## 1. Цель работы за период

Сформулировать задачу проекта, определить минимальный пользовательский сценарий, выбрать датасет и модель для обучения, а также подготовить базовую структуру репозитория.

## 2. Что было сделано

- Определена задача проекта: разработать веб-приложение, которое принимает фотографию российского кассового чека и возвращает список товарных позиций с их стоимостью.
- Зафиксирован MVP. Модель должна извлекать только два поля:
  - название товара;
  - стоимость товарной позиции.
- Определён основной набор данных — [cdek-ocr/receipt-ocr-ru](https://huggingface.co/datasets/cdek-ocr/receipt-ocr-ru).
- Изучена структура датасета. Для проекта необходимы поля `image`, `item_texts` и `item_sums`.
- Подтверждены размеры выборок датасета: 699 примеров в `train`, 149 в `val` и 151 в `test`.
- Выбрана модель [Donut](https://github.com/clovaai/donut) и исходный checkpoint [naver-clova-ix/donut-base](https://huggingface.co/naver-clova-ix/donut-base) для последующего fine-tuning.
- Определён минимальный пользовательский сценарий: загрузка чека, отображение распознанных товаров и возможность вручную исправить результат.
- Подготовлена верхнеуровневая структура частного репозитория проекта:

```text
receipts/
├── README.md
├── ml/
│   ├── data/
│   └── notebooks/
├── backend/
├── frontend/
└── reports/
```

- В README описаны цель проекта, датасет, модель, используемые технологии и продуктовые критерии готовности MVP.

## 3. Архитектура MVP

Предварительно выбрана следующая схема взаимодействия компонентов:

```text
Пользователь
    ↓
React frontend
    ↓ изображение чека
Python backend
    ↓
Donut inference
    ↓
JSON со списком товаров
    ↓
React frontend
```

Для backend планируется использовать Python. Frontend будет реализован на React и TypeScript.

## 4. Целевой результат модели

Модель должна возвращать результат следующего вида:

```json
{
  "items": [
    {
      "name": "Молоко Простоквашино",
      "sum": "89.99"
    }
  ]
}
```

Распознавание магазина, ИНН, адреса, даты, времени, скидок, НДС и итоговой суммы чека в MVP не входит.
