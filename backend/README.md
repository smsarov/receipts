# Локальный API

Из корня репозитория установите зависимости API в окружение модели и запустите сервер:

```bash
ml/.venv/bin/python -m pip install -r backend/requirements.txt
ml/.venv/bin/python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

Для запуска нужны зависимости и веса модели; подготовка описана в [ml/README.md](../ml/README.md). Модель загружается при первом запросе и остаётся в памяти. Первое распознавание может занять больше времени.

`POST /api/recognize` принимает `multipart/form-data` с полем `file` (JPEG, PNG, WebP, до 15 МБ) и возвращает JSON вида `{"items": [...]}`. `GET /api/health` проверяет доступность сервера, но не загружает модель. Загруженные изображения хранятся во временном каталоге только на время обработки. Результаты нуждаются в проверке человеком.
